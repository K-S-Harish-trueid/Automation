STEP 3 -- reset_cms ("Inputs from CMS")
================================================================================
TYPE      auto (runs automatically, no operator input)
CODE      backend/app/pipeline/stages/reset_cms.py :: stage_reset_cms_fields

WHAT IT DOES
Guarantees ACCOUNT_TYPE/CARD_TYPE/CARD_PROGRAM/CARD_STATUS are only ever
populated by the CMS Data Integration step (step 8) later on, never by
stale source data or the step-2 historical override.

CONSTRAINTS
  1. Unconditionally blanks (sets to "") these four columns, for every row:
     ACCOUNT_TYPE, CARD_TYPE, CARD_PROGRAM, CARD_STATUS.
  2. Runs regardless of what step 2 (replace) did or didn't fill in -- any
     values those fields held going into this step are discarded.
  3. No validation, no flagged rows, no operator interaction.

EDITABLE FIELDS
None -- fully automatic.

ADVANCE RULE
Always advances immediately; there is nothing to wait on.
